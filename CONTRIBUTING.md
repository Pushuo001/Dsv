# Contributing to DSV

Thanks for your interest in DSV.

We are building a community-first open project focused on more vivid local video playback through DualSense haptic feedback. The goal is to make video watching more immersive and emotionally engaging without sacrificing openness, collaboration, and safety.

## Ways to contribute

You can contribute in many ways, even if you are not a developer.

### If you are a developer

- build the local playback pipeline
- integrate DualSense output / HID / runtime logic
- implement timeline matching (hash or audio fingerprint)
- help with UI or editor tooling
- improve docs and examples

### If you are not a developer

- test early builds
- create haptic timeline examples
- write docs or tutorials
- translate content
- help with community moderation and issue triage
- share feedback on UX and workflow

## Principles

We value:

- openness
- respectful collaboration
- clear documentation
- safety and legal compliance
- incremental improvements over hype-driven shortcuts

## Before you start

Please read:

- [README.md](../README.md)

## Good first issues

If you are new here, look for issues labeled:

- `good first issue`
- `documentation`
- `community`
- `testing`
- `timeline`

These are beginner-friendly and designed to help new contributors get started quickly.

## Workflow

1. Fork the repository or create a branch
2. Make your changes with clear commit messages
3. If needed, create a draft issue or discuss the idea before large changes
4. Open a pull request with a short explanation
5. Wait for review and feedback

## Code of conduct

We expect all contributors to behave respectfully and professionally. Please read [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## Security

If you discover a security issue, do not open a public issue. Please follow the reporting process in [SECURITY.md](../SECURITY.md).

## Legal / safety note

This project is about local video playback and haptic feedback. Please do not upload or distribute copyrighted media files. All uploaded timeline data should be associated with media that the uploader has the right to use. Respect local laws, platform rules, and intellectual property.

---

We welcome contributions at any level. If you are unsure where to start, open an issue and ask. We are happy to guide you.
