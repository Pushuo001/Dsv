# Roadmap

## Early stage

- define project scope and contribution model
- decide technical stack for the first demo
- draft a minimal haptic timeline schema
- create example timeline files
- define basic developer workflow

## Next stage

- build a local demo for Windows playback
- integrate a basic haptic trigger layer
- support a simple timeline matching flow
- add documentation for local testing

## Later stage

- support more advanced haptics patterns
- improve timeline editor UX
- add automatic matching using audio fingerprinting
- improve runtime synchronization and review tools

## Community stage

- open an issue tracker with clear labels
- add documentation for new contributors
- encourage community-authored sample timelines
- establish review and moderation practice
